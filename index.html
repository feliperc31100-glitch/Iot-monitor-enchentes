Sobre o Projeto

O Sistema de Monitoramento Pluviométrico foi desenvolvido para detecção precoce de riscos de alagamento e enchentes em áreas urbanas.

Utilizando um microcontrolador ESP32 integrado a sensores de nível d'água, o sistema realiza a leitura contínua dos níveis e envia notificações automáticas em tempo real para o Telegram e para esta plataforma web via Firebase Realtime Database.
